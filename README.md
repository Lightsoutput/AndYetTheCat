# 《但是还有猫咪》
## 游戏介绍
《但是还有猫咪》（AndYetTheCat）是一款主打情感叙事与伙伴协作的温馨解谜游戏。

## 核心玩法
玩家扮演「引导者」，与可以感知记忆碎片的「灵猫」结伴冒险。通过鼓励小猫、抱起小猫跨越障碍、投掷鱼干引导灵猫触发机关，最终收集记忆碎片，修复一段段珍贵的回忆故事。

## 个人负责内容
主界面、加载界面、基础3C移动、第一关整体流程与玩法开发
